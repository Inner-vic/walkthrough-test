# 运维与故障处理

## 查看与恢复

从 `start` 输出取得精确 `record_path`，用宿主 `status` 或有界 `wait` 跟踪。终态为 `completed` 或 `failed`；聊天等待结束不等于后台任务已停止。`queued` 表示已落盘；只有实际执行/发送证据才能确认后续阶段。

`resume --record` 保留原请求、角色、来源、时钟、执行配置和检查点。已完成来源幂等返回；旧 final 仅在严格绑定下恢复未完成交付。未知发送/复制结果先核对 checkpoint，不盲目重试创建或发消息。锁由操作系统持有，不按文件年龄删除锁。

## 常见故障

| 现象 | 检查与处理 |
| --- | --- |
| `execution_disabled` | 核对目标安装清单；未验收候选保持禁用，不创建任务 |
| `deployment_incomplete` / 静态隔离失败 | 对照 settings、isolation、解释器、home 和独立 runtime，不改身份字段绕过 |
| User 过期 / 授权续期失败 | 区分可续期 access 过期、refresh 失效/撤销、身份不符和权限不足。后几项由管理员/固定用户恢复授权后恢复精确任务 |
| 时间无法验证 | 保留原文和同一 received_at；只追问缺失项。连字符简写范围不应被当作时区；完整 ISO 时区不能改写 |
| 车云查询失败 | 保留有限环境/状态/尝试诊断。权限、网络、分页或响应异常不作为空结果、不切换环境 |
| 下载中断 / 429 / 5xx | 有限重试；仅复用本任务计划内具有完成凭据且重新校验通过的文件 |
| 400 / URL 或来源校验失败 | 明确停止；不改写 URL、不跳过必需文件、不借其他时段来源填补 |
| 无可信制品码 | 保留统计结果，恢复原查询绑定；不使用最近卡片或 XXXX 发布完整报告 |
| revision 改变或不可用 | 恢复完整七子表读取；不能覆盖已交付表的人工改动 |
| 发布成功但无送达凭据 | 不标记 completed；核对精确来源 checkpoint 后再决定恢复 |
| worker 中断 | 调度器标记明确失败，保留原始记录；人工核对后显式 resume，不自动重放已开始任务 |

## 健康检查与数据

授权维护工具支持 `--check-only` 和 `--force-verify`，参数见 `--help`。它不创建走查任务；如需周期维护，由目标管理员按相同身份配置计划任务。默认配置不会向外发送健康通知。

原始日志按单任务保留策略清理；来源、规则快照、分析与发布审计、结果和送达 checkpoint 用于恢复。私有数据目录不得加入仓库，也不能把真实 token、CLI 原始输出、请求上下文、任务/群标识直接发到会话。

后台已向该来源确认交付后，接入端不再发第二条完成通知，最终输出独占 `NO_REPLY`。失败或未确认送达时普通回复一次脱敏事实和下一步；独立追问按精确来源或显式任务编号处理。
